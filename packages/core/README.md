# renkei-core

renkei（連携）のコア: LINE Login / LIFF / Messaging API の ID プリミティブ。HTTP フレームワーク非依存。
普通は [`renkei-server`](https://www.npmjs.com/package/renkei-server)（OIDC プロバイダーとして動く本体）か CLI の [`renkei`](https://www.npmjs.com/package/renkei) を使ってください。このパッケージは自分の HTTP 層に組み込みたい場合向けです。

Core of renkei (連携): LINE Login / LIFF / Messaging API identity primitives, framework-free.
Most people want [`renkei-server`](https://www.npmjs.com/package/renkei-server) (the OIDC provider) or the [`renkei`](https://www.npmjs.com/package/renkei) CLI; use this package to embed the primitives in your own HTTP layer.

# セキュリティポリシー / Security Policy

renkei は認証コンポーネントです。脆弱性の報告は最優先で扱います。

## 報告方法 / Reporting

- **GitHub の Private Vulnerability Reporting** を使ってください（Security タブ → Report a vulnerability）。
- 使えない場合は achraf@reyani.dev へ。件名に `[renkei security]` を付けてください。
- **公開 Issue には書かないでください。**

Use GitHub Private Vulnerability Reporting (Security tab → Report a
vulnerability), or email achraf@reyani.dev with `[renkei security]` in the
subject. **Do not open a public issue.**

## 対応 / Response

- 48時間以内に受領を返信します / Acknowledgement within 48 hours
- 深刻度に応じて修正・公開時期を相談します / Fix and disclosure timeline agreed by severity
- 修正リリースの Release Notes と GitHub Security Advisory でクレジットします（希望される場合）/ Credit in release notes and the advisory if you wish

## 対象バージョン / Supported versions

v0.x の間は最新のマイナーバージョンのみ対応します。
During v0.x only the latest minor version receives fixes.
